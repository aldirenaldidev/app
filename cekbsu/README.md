# Cek BSU

Aplikasi panduan Bantuan Subsidi Upah (BSU) — **BUKAN aplikasi resmi pemerintah**.

**Package:** `com.flexurio.cekbsu` | **Versi:** 1.0

## Fitur
- Syarat penerima BSU (checklist)
- Jadwal/tahapan pencairan
- Tautan resmi: Kemnaker, BPJS Ketenagakerjaan, JMO, PosPay
- Cek Desil (penjelasan desil 1-10, cara cek, tabel kelayakan)
- Berita & update, FAQ
- Disclaimer nonresmi di setiap layar utama

Aplikasi WebView offline, tautan resmi dibuka di browser eksternal.

## Build
```bash
./build.sh
```
