# DompetKu

Aplikasi pencatat keuangan pribadi dengan AI asisten offline.

**Package:** `com.flexurio.dompetku` | **Versi:** 1.1

## Fitur
- Catat pemasukan & pengeluaran dengan input rupiah otomatis
- AI auto-kategorisasi (~450 keyword Indonesia, brand, singkatan, typo)
- Parsing nominal: `15000`, `25rb`, `50k`, `1,5jt`, `2 juta`
- Belajar adaptif dari koreksi pengguna (SQLite)
- Budget Plan otomatis berbasis gaji
- Target Tabungan dengan analisis & proyeksi
- Skor Kesehatan Keuangan 0-100 + insight
- AI Asisten: tips hemat konkret + estimasi penghematan
- Profil: foto, nama, backup/restore JSON
- Semua offline, tanpa API eksternal

## Build
```bash
./build.sh
```
