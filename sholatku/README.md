# SholatKu

Aplikasi jadwal sholat, dzikir, dan doa. Kandidat pertama untuk Google Play Store.

**Package:** `com.flexurio.sholatku` | **Versi:** 2.0.12

## Fitur
- Jadwal sholat + imsakiyah (data pre-download, cache-first)
- Dzikir pagi/petang, kumpulan doa
- Widget jadwal sholat
- Alarm adzan

## Build
```bash
./build.sh        # APK
./build_aab.sh    # AAB untuk Play Store
```

File rilis (privacy policy, store listing) ada di `release/`.
