# BursaKu

Aplikasi saham Indonesia ala RTI Business.

**Package:** `com.flexurio.bursaku` | **Versi:** 2.0.2

## Fitur
- Pasar: IHSG, LQ45, status bursa, USD-IDR, emas, minyak
- Ranking: Top Gainer/Loser/Teraktif, Top Dividen
- LQ45 Heatmap, Watchlist, Detail emiten (candlestick + 13 indikator teknikal)
- Analisa Teknikal (BELI/TAHAN/JUAL), Alert Harga
- Berita (RSS), Portofolio + export CSV, Home widget
- Data: Yahoo Finance (delay ±15 menit), cache-first

## Build
```bash
./build.sh
```
