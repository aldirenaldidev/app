## Deskripsi lengkap
BursaKu adalah aplikasi analisa pasar saham Indonesia (IDX) untuk investor
ritel — lengkap secara teknikal dan fundamental, tanpa biaya berlangganan.

FITUR UTAMA (v2.0 "Senja Berani"):
• Dashboard baru: kartu hero IHSG + ringkasan portofolio + watchlist dengan sparkline
• Tampilan baru: aksen oranye–marun "Senja Berani" + bottom nav floating
• Logo resmi 20 emiten terpopuler (BBCA, BBRI, TLKM, dll) di watchlist, ranking & detail
• Loading jauh lebih cepat: tampil instan dari cache + fetch paralel
• Ringkasan pasar: IHSG, LQ45, status bursa, USD/IDR & 8 komoditas
  (emas, perak, Brent, WTI, tembaga, batubara, nikel, timah)
• Ranking: Top Gainer, Top Loser, Teraktif, dan Top Dividen (semua emiten IDX)
• Grafik candlestick + 13 indikator: RSI, MACD, Bollinger Bands, Stochastic,
  ATR, CCI, Williams %R, OBV, ADX, Ichimoku, Parabolic SAR, SMA, EMA
• Grafik intraday 5 menit untuk pantau sesi berjalan
• Analisa Teknikal otomatis: verdict BELI/TAHAN/JUAL beserta alasannya
• Data fundamental: laba rugi, neraca, arus kas, valuasi (P/E, P/BV),
  pertumbuhan, dividen & riwayatnya, komposisi pemegang saham
• Heatmap pasar LQ45
• Alert harga: notifikasi saat saham menyentuh target Anda
• Berita pasar terkini (CNBC Indonesia & IDX Channel)
• Portofolio: catat transaksi, pantau untung/rugi, ekspor ke CSV
• Autocomplete 940 emiten IDX — cari by kode atau nama perusahaan
• Widget layar utama: IHSG + watchlist tanpa buka aplikasi
• Sepenuhnya otomatis: data diperbarui sendiri + mode offline cerdas

CATATAN: Data pasar memiliki jeda ±15 menit dan berasal dari Yahoo Finance.
Analisa teknikal bersifat edukasi dan BUKAN rekomendasi investasi.

# Panduan Data Safety (diisi di Play Console)

Jawaban yang sesuai untuk BursaKu:

1. **Apakah aplikasi mengumpulkan atau membagikan data pengguna?**
   Ya — Advertising ID (wajib karena ada iklan AdMob).

2. **Jenis data** → Pengenal perangkat atau pengenal lainnya →
   **Advertising ID**:
   - Dikumpulkan: Ya
   - Dibagikan: Ya (ke Google AdMob / partner iklan)
   - Tujuan: Periklanan & pemasaran
   - Ephemeral (diproses sementara): Tidak

3. **Data pribadi sensitif lain** (nama, email, lokasi presisi, kontak,
   dll): **Tidak dikumpulkan.**

4. **Apakah data dienkripsi saat transit?** Ya (HTTPS).

5. **Apakah pengguna dapat meminta penghapusan data?** Tidak relevan —
   tidak ada akun dan tidak ada data pribadi yang disimpan di server.
   Data watchlist/alert/portofolio hanya ada di perangkat dan dapat
   dihapus dengan menghapus data aplikasi / uninstall.

6. **Kebijakan privasi**: wajib isi URL publik file privacy-policy.html
   (user harus meng-host sendiri — lihat CHECKLIST RILIS).
